## Features

- **Signature Appearance**: Custom red-black gradient aesthetic and sleek theme options.
- **Complete Ghost Mode**:
  - Read messages without sending read receipts.
  - Disable typing indicators ("typing...", "recording audio...").
  - Hide online status (stay offline).
  - Incognito Telegram Stories view.
- **Message Logger & History**:
  - Retain deleted messages with timestamp indicators.
  - View edit history of modified messages.
  - Retain self-destructing (TTL) media.
- **Restriction Bypasses**:
  - Save and forward media from restricted channels (`noforwards` bypass).
  - Unlimited screenshot capture.
  - Block Telegram sponsored ads.
- **Power Tools**:
  - Inspect peer IDs, DC numbers, and registration dates.
  - RegEx-based message filters.
  - Streamer mode for concealing sensitive info.
